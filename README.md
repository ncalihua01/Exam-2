# Problem 1
Given a dictionary of students' names as keys and their grades as values and a threshold number, write a function, filter_grades, to filter out and print names of students who have grades above the specified threshold.

# Problem 2
A file contains rows of comma-separated values.  Write a program that reads the file and prints the sum of the numbers on each line.

# Problem 3
Write a function, normalize_numbers, which takes in a two-dimensional array of numerical data and normalizes the data so that all values are between 0 and 1.

# Problem 4
A classical dataset to work with is the data from the Titanic tragedy: https://www.kaggle.com/datasets/yasserh/titanic-dataset/data.  There is missing data in the dataset, particularly in the 'Age' and 'Cabin' columns.  Write a program which does the following.  Compute the percent of missing data in each.  Then appropriately handle the missing data, making a comment for how you've decided to handle them, and save the updated data to a new csv file named cleaned_titanic.csv.  Compute the average age of the passengers overall, the average age of the survivors, and the average age of the survivors for each of the ticket classes.
